# Habit Tracker

Простой веб-приложение для отслеживания ежедневных привычек, созданный на PHP.

## ✨ Особенности

- ✅ Добавление новых привычек
- ✅ Отметка выполнения привычек
- ✅ Удаление отдельных привычек
- ✅ Очистка всего списка
- ✅ Статистика выполнения
- ✅ Данные сохраняются в сессиях

## 🛠️ Технологии

- **PHP 8+** (сессии, обработка форм)
- **HTML5** (семантическая верстка)
- **CSS3** (Flexbox, адаптивный дизайн)
<!-- - **JavaScript** (необязательно, для улучшений) -->

## 📦 Установка

1. Клонируйте репозиторий
2. Поместите файлы в папку вашего веб-сервера
3. Откройте `index.php` в браузере

## 🎯 Функциональность

- Добавление привычек через форму
- Визуальное отображение прогресса
- Статистика по выполнению
- Временное хранение данных (сессии)
